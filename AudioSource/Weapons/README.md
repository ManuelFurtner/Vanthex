# Vanthex weapon audio sources

The current bank contains 119 mono source files. Three shared `EquipmentMove` variants combine a foot contact with quiet cloth/strap motion in the same short action. Their selection and timbre do not read armor tier, armor points or inventory. Authoritative grounded distance drives cadence; idle, airborne, dead, inactive-round and teleport samples reset it. Crouching reduces gain to 32%. Movement ranks below gunshots and above mechanics, using the same spatial routing and voice budget.

All WAVs in this directory are original, deterministic procedural synthesis generated for this project. No downloaded recordings, third-party samples, or library assets are included. The sounds are designed game signatures rather than claims of authentic firearm recordings. They may be edited and redistributed with Vanthex.

Regenerate with Python 3: `python AudioSource/Weapons/generate_weapon_audio.py`. The generator uses only the standard library, stable per-file seeds, mono 48 kHz PCM16, short envelopes, and at least 6 dB peak headroom. `manifest.json` records duration, format, peaks and SHA-256 for every file.

Import with the built Unreal editor commandlet: `UnrealEditor-Cmd.exe Vanthex.uproject -run=VanthexBuildWeaponAudio -unattended -nop4`. Add `-ReplacePrototypeAssets` to deliberately refresh existing assets. The commandlet creates `/Game/Vanthex/Audio/Weapons/DA_WeaponAudio`, editable per-weapon event banks, spatial attenuation and concurrency assets.

Shots have three variants for Pistol, P250, MP5, MP7, M4, AK, AUG, DMR and Shotgun. Each firearm also has separate mechanics, magazine/bolt reload phases, dry fire, draw and holster. Knife has draw/holster/swing. UI includes accepted/rejected purchases and phase transitions. One quiet diffuse room tail supplies short reflections without duplicating a gunshot transient. The existing bullet near-miss/impact router remains independent.

At the 24-voice budget, a new higher-priority event replaces the lowest-priority active voice; equal or lower priorities remain capped. Other players' shots and knife swings outrank the listener's own shot, then reload/equipment/mechanics, UI and room tails. Server packets identify the listener's own source (including a spectated pawn). The same priority is assigned before Unreal playback and enforced by `StopLowestPriorityThenPreventNew`; distance gain does not reverse this ordering. Regenerate the asset settings with `-ReplacePrototypeAssets` after updating from the previous PreventNew policy.

World events are authorized by the server and addressed only to audible listeners. GRID acoustics use its actual corridor and stair topology, visibility traces for current obstruction (including moved doors), shortest available paths, path distance, low-pass filtering, and muffled transmission when no open path exists. The graph samples centerlines and updates obstruction at most every 100 ms; it is a bounded game approximation, not wave propagation. Stereo panning is supported; no HRTF elevation accuracy is claimed.

## Verified output — 2026-11-03

Import passed with 119 WAVs and ten weapon banks. All 14 groups in the combined automation run passed, including `Vanthex.WeaponAudio.CompleteMonoBanks`, `EquipmentMovementCadence`, `MixPriorities` and `PhysicalPortalAndWall`. See the [build/import report](../../Docs/Validation/EconomyArmorAudio/BuildAndImport.txt) and [automation results](../../Docs/Validation/EconomyArmorAudio/Automation.json).

The [real mixer probe](../../Docs/Validation/EconomyArmorAudio/WeaponAudioPlayback.txt) passed 13 checks, including seven rendered events, duplicate suppression, reload cancellation, late-phase rejection, missing assets, shared movement playback, isolated shot counters, voice limits, danger-priority preemption, authoritative delivery and range. The [recording](../../Docs/Validation/EconomyArmorAudio/WeaponAudioPlayback.wav) contains 428,032 stereo frames at 48 kHz (8.917 seconds), with peak 0.180939 / −14.85 dBFS and zero samples at or above the 0.999 clipping threshold.

The [waveform analysis](../../Docs/Validation/EconomyArmorAudio/WeaponAudioPlayback-analysis.json) confirms nonzero output in all seven event windows. The left AUG event has RMS 0.0177533 on the left and zero on the right; the right MP7 has zero on the left and RMS 0.0116994 on the right. The injected muffled AUG event has RMS 0.0008826 per channel, versus 0.0088577 for the unfiltered rear AUG event. Physical portal routing is tested separately; this recording verifies the supplied gain/filter playback, not a full-match doorway listening test.

Reproduce using `-WeaponAudioPlaybackTest -RenderOffscreen -audiomixer -ini:Engine:[Audio]:UnfocusedVolumeMultiplier=1.0 -ExecCmds="t.MaxFPS 60,au.NeverDisableSubmixes 1"`, with actual graphics/audio initialized. Then run `python AudioSource/Weapons/analyze_playback.py Saved/WeaponAudioPlayback.wav`. The probe exits after writing its report and WAV. Above/below sound generation is verified, but equal stereo channel levels do not establish elevation or front/back perception. Human headphone/speaker listening, weapon recognition, final mix, adverse-network behavior and sustained load evaluation remain open.
