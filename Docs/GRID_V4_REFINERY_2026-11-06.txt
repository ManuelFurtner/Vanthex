VANTHEX / GRID V4 / REFINERY VISUAL UPGRADE
Date: 2026-11-06

PURPOSE AND SCOPE
Apply the supplied references' industrial construction, connected utilities,
material separation and practical lighting to the existing playable layout.
No reference pixels, meshes, proprietary level layouts or purchased content were
used. All newly authored environment meshes and maps in ArtSource/Refinery are
original. The existing layout, floor collision, routes, cover and game rules remain.

AUTHORING AND IMPORT
Blender 4.5.14 LTS background Python authors editable collection-based sources.
ArtSource/Industrial preserves the initial Blender edition.
ArtSource/Refinery/Vanthex_Refinery.blend contains the detailed edition.
ArtSource/Refinery/industrial.json is the evaluated triangle/material interchange.
Build/Blender/build_industrial.py -- --refinery generates the source.
Build/Blender/refinery_details.py supplies the detailed module geometry.
Build/Blender/refinery_textures.py bakes 15 original seamless 2048x2048 PNG maps:
base colour, normal and packed AO/roughness/metallic for five material families.
Source/Vanthex/VanthexBlenderImport.cpp imports real MeshDescriptions, materials,
texture compression/colour-space settings and Nanite meshes into Unreal.
Latest verified import: 318,536 source triangles. This is the source library total,
not the rendered triangle count or an assertion about the entire world's geometry.

New details include formed/flanged pipes, cable ladders, copper/red utility runs,
louvers, electrical panels, process gauges/valves, data panels, server bays,
machinery fans, bolted structural channels, reactor coolant drives, a suspended
containment crown and flush floor grates with recessed pipes. Modules are instanced.
Placement remains generated from the existing room and connection data.

MATERIALS AND LIGHT
Physical world-scale projection separates concrete, floors, metal, paint and rubber.
The old runtime procedural-noise surface is replaced in the detailed edition by
texture-backed PBR materials. Detail includes pores, brushing, sparse coating wear
and restrained roughness variation. This is procedural authored wear, not scanned
photogrammetry or a bespoke texture set for every room.
Practical tube fixtures use downward rect key lights. Refined point fills use
explicit lumen units. Roof traces position key fixtures beneath actual ceilings.
Exposure and fill strengths were corrected after overexposed initial captures.
Existing Lumen GI/reflections and virtual shadow maps remain enabled.
No path-traced/offline Blender render is presented as playable Unreal output.

LIMITS AND REMAINING VISUAL WORK
This is a denser procedural industrial environment. It does not yet match the
reference images' bespoke modelling, irregular set dressing, surface storytelling,
animation or material variety. Repeated modules, broad clean floor areas and
generic room silhouettes remain visible. More identical panels alone will not
close that gap. Further work needs individual hero assets, room-specific equipment
assemblies and authored wear/decal composition, checked again in gameplay.
No claim of AAA/CS/Rainbow-equivalent graphics, universal frame rate, freedom from
every visual intersection or a human competitive playtest is made.
Twinmotion was not used; the Computer Use kernel failure remains a separate issue.
The reproducible Blender/Unreal commandlet pipeline runs without GUI automation.
No purchase, paid service, Edgegap deployment or raw licensed asset publication
was performed for this upgrade. Existing local licensed character/weapon assets
are outside the newly original environment library.
